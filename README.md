# 📺 MiniTube - Video Sharing Platform

MiniTube is a lightweight, web-based video sharing platform prototype built with PHP and MySQL, designed to replicate core video streaming and community features.

---

## ✨ Key Features

* User Authentication: Registration and login system (login.php, login.html).
* Personalized Feed: Video browsing and dynamic content feed (feed.php).
* Channel Pages: Dedicated channel views displaying creator details and uploads (channel.php).
* Video Player & Watch Page: Streamlined watch interface for media playback (watch.php).
* Automated Setup & Mock Data: Built-in SQL setup scripts and sample data generators (sql.php, install.php, generate_data.php).
* Documentation & Schemas: Includes relational diagrams, ER schemas, and action flow charts.

---

## 🛠️ Tech Stack

* Backend: PHP
* Database: MySQL / MariaDB
* Frontend: HTML5, CSS3

---

## 🚀 Getting Started

1. Clone the repository:
   git clone https://github.com/linasahin/Minitube-Video-Platform.git

2. Database Setup:
   * Import the schema using sql.php or execute the script via install.php.
   * Populate sample records using generate_data.php.

3. Run Locally:
   * Place the files inside your local web server root directory (e.g., htdocs in XAMPP or www in WampServer).
   * Open your browser and navigate to http://localhost/Minitube-Video-Platform/index.html.
